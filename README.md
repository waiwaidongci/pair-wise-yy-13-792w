# hxyfront-62012 染整实验室 · 色差复评台

在原小样管理页基础上扩展的色差复评工作台，面向下午连续评多块新样的场景。同一块布在不同灯箱（D65 / TL84 / CWF / A）下分别评色，记录独立留存。

## 评色规则（由 `src/lab/decide.ts` 唯一裁决）

1. **先选灯箱并登记**：每次评色先选灯箱，登记标准白板读数与环境温湿度。
2. **校准门槛**：校准过期或白板读数 |ΔE| 越限时，只能登记「待校色」，**禁止给出通过结论**；两名评色员数据照实留存。可在灯箱面板登记重新校准。
3. **双人同箱**：两名评色员在同一灯箱下分别测量，色差均 **ΔE₀₀ ≤ 0.8 且结论一致**才判通过；
   - 一致不通过 → 不通过；
   - 结论不一致（含一人过、一人不过）→ **进入仲裁**，两份原始记录都保留；
   - 仲裁由第三人在同一灯箱复测，出具「仲裁通过 / 仲裁驳回」，甲乙原始记录仍不可改。
   - ΔE 数值始终来自测量（CIEDE2000），ΔE>0.8 时评色员无权手工改判通过；仅允许在 ΔE≤0.8 时改判不通过。
4. **修改即重判**：配方 / 后整理 / 克重任一修改后，旧评色标记失效，批次状态与「只看订单可通过」筛选立即重新判定；旧配方版本与旧评色记录只标记不删除，在「历史版本」中可查。
5. **同步更新**：批次列表、色差超限数、待校色、仲裁数、通过率、Lab 对比均由同一份台账派生，写入后一起刷新。

## 分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 判定 | `src/lab/decide.ts`、`src/lab/color.ts` | 纯函数：校准预检、双人结论合成、ΔE00（已过 Sharma 标准向量）、批次有效状态、指标 |
| 存档 | `src/lab/archive.ts`、`src/lab/seed.ts`、`src/lab/store.ts` | localStorage 持久化、评色/仲裁/校准/配方版本只追加不覆盖 |
| 交互 | `src/components/*`、`src/App.tsx` | 灯箱面板、评色登记、批次列表、Lab 对比/仲裁、配方修改、历史版本 |

## 技术栈与运行

React 19 + Vite + TypeScript（无后端，台账存浏览器 localStorage，可用页面右下角「恢复演示数据」重置）。

```bash
npm install
npm run dev      # http://localhost:62012
npm run build
```
